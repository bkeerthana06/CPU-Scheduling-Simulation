AIM

To implement CPU scheduling algorithms such as FCFS, SJF and Round Robin and calculate Completion Time, Turnaround Time and Waiting Time.

Procedure

  1. Enter process ID, arrival time and burst time.
  2. Add the processes to the ready queue.
  3. Select the required scheduling algorithm.
  4. Enter time quantum for Round Robin.
  5. Click Run Simulation.
  6. Observe the Gantt chart.
  7. Calculate CT, TAT and WT.
  8. Compare the results of different algorithms.

Pseudo Code

START

Read number of processes

Read arrival time and burst time

Select scheduling algorithm

Initialize current time = 0

WHILE processes are incomplete

    Find available processes

    Select process according to algorithm

    Execute process

    Update current time

    Calculate completion time

END WHILE

TAT = CT - AT

WT = TAT - BT

Display Gantt chart and results

STOP

C Program - FCFS

#include <stdio.h>

int main()
{
    int n, i, j, time = 0;
    int at[20], bt[20];
    int ct[20], tat[20], wt[20];
    int pid[20], temp;

    printf("Enter number of processes: ");
    scanf("%d", &n);

    for(i = 0; i < n; i++)
    {
        printf("Enter PID, AT, BT: ");
        scanf("%d %d %d",
              &pid[i], &at[i], &bt[i]);
    }

    for(i = 0; i < n-1; i++)
    {
        for(j = i+1; j < n; j++)
        {
            if(at[i] > at[j])
            {
                temp = at[i];
                at[i] = at[j];
                at[j] = temp;

                temp = bt[i];
                bt[i] = bt[j];
                bt[j] = temp;

                temp = pid[i];
                pid[i] = pid[j];
                pid[j] = temp;
            }
        }
    }

    for(i = 0; i < n; i++)
    {
        if(time < at[i])
            time = at[i];

        time += bt[i];

        ct[i] = time;
        tat[i] = ct[i] - at[i];
        wt[i] = tat[i] - bt[i];
    }

    printf("PID AT BT CT TAT WT\n");

    for(i = 0; i < n; i++)
    {
        printf("%d %d %d %d %d %d\n",
        pid[i], at[i], bt[i],
        ct[i], tat[i], wt[i]);
    }

    return 0;
}

Frequently Asked Questions

1. What is CPU scheduling?
It is the method of selecting a process for CPU execution.

2. What is arrival time?
Time at which a process enters the ready queue.

3. What is burst time?
CPU execution time required by a process.

4. What is completion time?
Time at which a process finishes execution.

5. What is turnaround time?
TAT = Completion Time - Arrival Time.

6. What is waiting time?
WT = Turnaround Time - Burst Time.

7. What is Round Robin?
Each process gets a fixed CPU time quantum.

8. Which algorithm may cause starvation?
SJF may cause starvation for long processes.
